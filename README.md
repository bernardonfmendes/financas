# Finora

Controla · Organiza · Poupa

Aplicação pessoal de gestão financeira, para uso privado (PWA para iPhone).

## Requisitos

- Node.js 22 ou superior
- npm

## Instalação

```bash
npm install
```

## Desenvolvimento

```bash
npm run dev
```

## Verificação e build

```bash
npm run typecheck
npm run build
```

## Variáveis de ambiente

Copia `.env.example` para `.env.local` e preenche os valores. Só a chave pública (`anon`) do Supabase vai para o frontend.
